# Как ИИ слышит мир — fourier-sound-lab

Локальное веб-приложение (Django) для творческого задания по математике:
звук → ряд Фурье → ДПФ → спектрограмма → нейросеть. На каждом шаге формулы
показаны с реальными числами текущей записи. Полное ТЗ — в [SPEC.md](SPEC.md).

## Готовность

| Этап (SPEC §8) | Статус |
|---|---|

## Установка и запуск (Windows / macOS / Linux)

Нужен [uv](https://docs.astral.sh/uv/). Python 3.12 и зависимости он поставит сам.

```bash
uv sync                    # базовые зависимости (шаги 1–5)
uv sync --extra ml         # + PyTorch/transformers/scikit-learn (шаги 6–7)
uv run python manage.py runserver
```

Откройте **http://localhost:8000** (или 127.0.0.1). Микрофон в браузере работает
без HTTPS только на `localhost`; по IP в локальной сети запись не включится.

### Модели шага 6

```bash
uv sync --extra ml --inexact
uv run python scripts/download_models.py   # один раз: AST 330 МБ + CLAP 589 МБ в кэш Hugging Face
```

Ревизии закреплены в `analyzer/services/models.py`. После загрузки можно работать без сети:
`HF_HUB_OFFLINE=1`. Устройство выбирается автоматически (cuda → mps → cpu); чтобы не мешать
обучению на той же видеокарте, задайте `FSL_DEVICE=cpu` (PowerShell: `$env:FSL_DEVICE="cpu"`).
Модели загружаются в память при первом открытии шага 6 и дальше кэшируются.

ffmpeg ставить не нужно: используется бинарник из пакета `imageio-ffmpeg`.
Plotly.js и KaTeX лежат в `analyzer/static/vendor/`, поэтому интернет для работы страницы не нужен.
Обновить их: `uv run python scripts/fetch_static.py` (версии закреплены, sha512 проверяется).

PyTorch по умолчанию ставится с CUDA 13.2 (колёса `cu132`, поддерживают RTX 2060 Super / sm_75).
На macOS ставится обычная сборка с MPS.

## Тесты

```bash
uv run pytest
```

- `tests/test_fourier.py` — аналитические тесты математики (SPEC §7 и сверх него):
  пик и амплитуда синуса, два пика, обратное ДПФ, Парсеваль, наивное ДПФ = `numpy.fft.fft`,
  коэффициенты меандра/пилы/|x| против точных формул, Гиббс ≈ 8,95% скачка (и медленная
  сходимость для пилы), монотонность RMSE(N), Бессель, ортогональность, оценка периода.
- `tests/test_sampling_audio.py` — алиасинг 5 кГц → 3 кГц при fₛ = 8 кГц, антиалиасинговый фильтр,
  восстановление, моно/обрезка/ресемплинг, проверки качества, декодирование через ffmpeg.
- `tests/test_stft.py` — тон, свип, щелчок на спектрограмме, Парсеваль для STFT, совпадение с librosa (STFT и мел-банк), граница Габора 1/(4π), разрешение по частоте.
- `tests/test_probs.py` — сигмоида, softmax (и связь softmax двух классов с сигмоидой), энтропия, точный SNR шума,
  градиенты BCE и CE (σ − y, p − onehot) против конечных разностей.
- `tests/test_models.py` — настоящие AST и CLAP на CPU (пропускаются без весов): формы, нормировка входа,
  чистый тон → «Sine wave», softmax CLAP, z = e^s·cos, API классификации.
- `tests/test_views.py` — все API шагов 1–5 на каждом примере галереи, загрузка, ошибки, изоляция сессий.

## Устройство

```
analyzer/services/   чистая математика и обработка, без Django
  fourier.py         ряд Фурье, ДПФ, окна, пики, Парсеваль, редактирование спектра
  sampling.py        дискретизация с фильтром и без, восстановление, частота алиаса
  audio.py           декодирование (ffmpeg), моно, ресемплинг, проверки качества
  steps.py           сборка данных для шагов интерфейса
  store.py           записи во временной папке media/sessions/<id сессии>/
analyzer/views.py    тонкий HTTP-слой (JSON API)
analyzer/templates/  одна страница со степпером
analyzer/static/     app.js, app.css, vendor/ (Plotly, KaTeX)
scripts/             make_samples.py, fetch_static.py
samples/             галерея
```

Записи пользователя хранятся в `media/` (не в git) и удаляются через 24 часа.

## Галерея

Сейчас все примеры **синтетические** (`scripts/make_samples.py`, seed 2026) и помечены в интерфейсе
как «синтез». Это простые физические модели: гласные через форманты, тон свиста, шумовые импульсы,
ЧМ-сирена, аккорд, модель насоса и та же модель с ударами подшипника. Перед защитой их лучше заменить
настоящими записями: положить WAV в `samples/` и добавить запись в `samples/manifest.json` с `"synthetic": false`.
Примеры насоса на этапе 5 будут взяты из DCASE.

## Безопасность и данные

- Токен Hugging Face только в переменной окружения `HF_TOKEN` или через `huggingface-cli login`.
- `.env`, `media/`, `data/`, `artifacts/*`, веса моделей и свои записи исключены из git (`.gitignore`).
- Для деплоя задать `FSL_SECRET_KEY`, `FSL_DEBUG=0`, `FSL_ALLOWED_HOSTS`.
