## Изолированное окружение

`training/pyproject.toml`, `training/uv.lock`, `training/.venv` принадлежат обучению.
Зависимости добавлять только через `uv add --directory training --optional ml …`.
Установка: `uv sync --directory training --extra ml --inexact`.
Не выполнять точную синхронизацию окружений во время параллельной работы.
Из корня проекта запускать:

```powershell
uv run --project training --extra ml --no-sync python training/prepare_data.py --config training/configs/prepare_esc50.yaml
uv run --project training --extra ml --no-sync python training/train_baselines.py --config training/configs/baselines.yaml --mode benchmark
uv run --project training --extra ml --no-sync python training/train_baselines.py --config training/configs/baselines.yaml --mode train
uv run --project training --extra ml --no-sync python training/evaluate.py --training-index artifacts/report_esc50/training_index_TIMESTAMP.json
```

Первый цикл CNN запущен из существующей корневой `.venv`, до выделения отдельного
окружения. Версии всех установленных пакетов сохранены в каждом запуске.
Следующие эксперименты должны использовать окружение обучения.

## AST на ESC-50

Обновление 3 ноября: старый запуск прервался. Текущий восстанавливаемый цикл:
`artifacts/report_esc50/ast_job_20261103_resumable/`. После каждой эпохи сохраняются
веса, AdamW, scheduler, GradScaler и RNG в safetensors/JSON с атомарным указателем
и SHA256. После пяти фолдов автоматически запускается `evaluate_ast.py`.
Состояние и итоги обновляются в корневом `CODEX.md`.

```powershell
training\.venv\Scripts\python.exe training/status_ast.py --job-dir artifacts/report_esc50/ast_job_20261103_resumable
training\.venv\Scripts\python.exe training/pipeline_ast.py --job-dir artifacts/report_esc50/ast_job_20261103_resumable --resume
```

Вторую команду использовать после остановки. Активный процесс защищён блокировкой
от второго запуска того же задания. Resume требует прежних кода, конфига,
окружения и данных. Незавершённая эпоха повторяется; проверка на синтетических
данных подтверждает совпадение с непрерывным обучением на CPU.

Конфиг: `training/configs/ast_esc50.yaml`. Веса исходной модели загружаются
только локально из общего кэша HF; приложения и кэш исходных весов не изменяются.
Аудио читается по батчам, `num_workers=0`; системная ОЗУ не занята всем датасетом.
При `max_length=512` сетка имеет 12×50 патчей (602 токена вместе с двумя
специальными), а не 12×51. Обрезаются соответствующие временные позиции каждой
частотной строки. Пройден тест сохранения и повторной загрузки через
`from_pretrained` без отсутствующих, лишних или несовпадающих весов.

Замер 2026-11-02: по 50 шагов оптимизатора для каждой фазы; один шаг — четыре
микробатча по четыре клипа. Первые пять шагов исключены из среднего времени.
Голова: 0,297 с/шаг; полное дообучение: 0,686 с/шаг. Оценка 1598 с/фолд,
7991 с на пять фолдов, без досрочной остановки и накладных расходов сохранения.
Практический резерв: 2,5–3 часа. Пик GPU allocated 1,58 ГиБ; минимум доступной
ОЗУ во время шагов 2,49 ГиБ (это системный показатель, зависит и от других программ).
Замер validation выполнен на 40 клипах только для оценки времени; его метрики
не являются итоговой оценкой качества. Полное обучение валидируется на всём val.

```powershell
uv run --project training --extra ml --no-sync python training/train_ast.py --config training/configs/ast_esc50.yaml --mode benchmark
uv run --project training --extra ml --no-sync python training/train_ast.py --config training/configs/ast_esc50.yaml --mode train
```

## ESC-50: отклонение от стандартного протокола

Зафиксирована версия `33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6`.
В метаданных обнаружены четыре Freesound ID в разных фолдах:
`131943`, `134049`, `209698`, `234879` (девять клипов).
Официальные тестовые фолды сохраняются целиком. Из validation исключаются
исходники, встречающиеся в test; из train — встречающиеся в validation или test.
Конкретные исключения записаны в `artifacts/prepare_esc50/split_audit.json`.
Это модифицированный протокол, его нужно обозначать при сравнении с публикациями.
У всех моделей одни и те же разбиения; test не используется для настройки.

Пробные 50 шагов — только замер скорости. Полное обучение начинается с нуля.
Конфигурация CNN фиксирована до финальной оценки: seed 2026, до 30 эпох,
batch 16, AdamW, warmup 10%, cosine schedule, patience 8 по validation macro-F1.
Сохраняются точные исходники запуска, конфиг, состояние git, версии пакетов,
хеши аудиофайлов train/validation, веса safetensors и TensorBoard.

## Контракт LOF — дополнение пользователя

В задаче C обязательно сохранить в `artifacts/anomaly_pump/lof/`:

- эмбеддинги AST отдельно для train, validation и финального test;
- манифест соответствия строк эмбеддингов файлам, ID машин и частям разбиения;
- закреплённую revision AST и параметры извлечения эмбеддингов;
- обученную модель LOF для каждого ID (`joblib`, загружать только собственные файлы);
- версии sklearn/joblib, параметры LOF, пороги по validation, метрики и ROC;
- любой обученный препроцессор, если он используется.

`novelty=True`, `n_neighbors=20`; fit только на нормальных train-эмбеддингах.
Данные и обученные артефакты не добавлять в git. Публикацию не выполнять.

## Общая последовательная очередь A → C → B

```powershell
training\.venv\Scripts\python.exe training/status_all.py
training\.venv\Scripts\python.exe training/pipeline_all.py --resume
```

Вторая команда нужна только после остановки процесса; активная очередь защищена
блокировкой. Она ожидает текущую AST на ESC-50, затем обучает ID-CNN/LOF, делает
50-шаговый замер проектной AST, обучает её и готовит реальные примеры галереи,
отчёт, сценарий защиты и презентацию из фактических метрик. В конце выполняются
локальные проверки приложения. Визуальная проверка финальной презентации —
отдельный этап после её генерации. Статус: `artifacts/all_tasks/status.json`.

Данные C — официальный DCASE 2020 dev pump с проверенным checksum, лицензия
CC BY-NC-SA 4.0. ID-CNN сохраняет модель, AdamW и RNG после эпохи; LOF сохраняет
все эмбеддинги и обученные объекты. Не удалять промежуточные артефакты для resume.

Данные B — 2468 публичных клипов FSD50K (только CC0/CC BY), без ESC-50 и личных
записей. Используется своё разбиение по авторам: train 1464 / val 488 / test 516.
Whistling отсутствует в основном наборе 200 классов и взят из collection-разметки;
для него только 6/2/1 уникальных клипов. Это ограничение отчёта. Выборка train
балансируется по классам с возвращением, а не добавлением уникальных записей.
Test никогда не используется для настройки модели или порога.

Подготовка B общая с приложением: `common/project_audio.py`. Waveform после
ingest приводится librosa soxr_hq к 16 кГц и дополняется нулями до 10 секунд
перед ASTFeatureExtractor. Параметры и хеш исходника — audio_preprocessing.json.
50-шаговый замер проверяется на совпадение конфига и исходников перед запуском.
