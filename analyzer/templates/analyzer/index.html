Шаг 1. Звук как функция

Клик по волне выбирает участок для шагов 2–3.

Где здесь математика

Строго

Дискретизация. Запись хранит не функцию f(t), а её значения в равноотстоящих точках: x[n] = f(n\Delta t),\ \Delta t = 1/f_s.

Теорема Котельникова (Найквиста — Шеннона). Если спектр f ограничен: \hat f(\nu) = 0 при |\nu| \ge f_{\max}, и f_s > 2 f_{\max}, то f однозначно восстанавливается по отсчётам:

f(t) = \sum_{n=-\infty}^{\infty} x[n]\,\operatorname{sinc}\!\left(\frac{t - n\Delta t}{\Delta t}\right),\quad \operatorname{sinc} u = \frac{\sin \pi u}{\pi u}.

Частота f_s/2 называется частотой Найквиста.

Алиасинг. Синусоиды с частотами f и f + m f_s дают одинаковые отсчёты: e^{2\pi i (f + m f_s) n\Delta t} = e^{2\pi i f n \Delta t}\,e^{2\pi i m n} = e^{2\pi i f n \Delta t}. Поэтому частота выше f_s/2 после дискретизации неотличима от |f - f_s\cdot\operatorname{round}(f/f_s)|.

Почему нужен фильтр. Реальный звук не имеет строго ограниченного спектра, поэтому перед понижением частоты всё выше f_s/2 подавляют фильтром нижних частот. Здесь это полифазный КИХ-фильтр с окном Кайзера (scipy.signal.resample_poly). Без фильтра частоты выше f_s/2 «заворачиваются» и слышны как посторонние тоны.

Что вы слышите. Браузер не играет звук при 2 кГц, поэтому отсчёты восстанавливаются обратно до исходной частоты фильтром нижних частот с частотой среза f_s/2, то есть приближением формулы с sinc. Искажения от алиасинга при этом сохраняются: восстановление не может отличить «завёрнутую» частоту от настоящей.

Оговорка. Если исходная частота записи не делится на f_s нацело (48 → 44,1 кГц), то для варианта без фильтра значение f(n\Delta t) берётся линейной интерполяцией между соседними отсчётами записи: исходной непрерывной функции у нас нет.

Шаг 2. Сборка из гармоник (ряд Фурье)

Где здесь математика

Строго

Ряд Фурье. Для функции, интегрируемой на периоде T, \omega = 2\pi/T:

f(t) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n \cos n\omega t + b_n \sin n\omega t\right),\quad S_N(t) = \frac{a_0}{2} + \sum_{n=1}^{N}\left(a_n \cos n\omega t + b_n \sin n\omega t\right).

Условия Дирихле. Если на периоде f кусочно-непрерывна, имеет конечное число разрывов первого рода и конечное число экстремумов (кусочно-монотонна), то ряд сходится в каждой точке, и его сумма равна

\frac{f(t-0) + f(t+0)}{2}.

В точках непрерывности это просто f(t); в точке скачка — середина скачка.

Эффект Гиббса. Около точки разрыва со скачком h частичные суммы перескакивают предельное значение на

\left(\frac{1}{\pi}\int_0^{\pi}\frac{\sin u}{u}\,du - \frac12\right) h \approx 0{,}0895\,h,

то есть примерно на 8,95% скачка. С ростом N выброс не уменьшается, а сжимается к точке разрыва (максимум находится на расстоянии порядка T/(2N)). Сходимость поточечная, но не равномерная.

Неравенство Бесселя и равенство Парсеваля. Для f \in L^2 на периоде:

\frac{a_0^2}{2} + \sum_{n=1}^{N}(a_n^2 + b_n^2) \;\le\; \frac{2}{T}\int_0^T f^2(t)\,dt, \qquad \frac{a_0^2}{2} + \sum_{n=1}^{\infty}(a_n^2 + b_n^2) = \frac{2}{T}\int_0^T f^2(t)\,dt.

Наилучшее приближение. Среди всех тригонометрических многочленов степени \le N частичная сумма S_N минимизирует \|f - P\|_{L^2}: это ортогональная проекция на подпространство, натянутое на 1, \cos n\omega t, \sin n\omega t,\ n \le N. Поэтому \|f - S_N\| не возрастает с ростом N (график RMSE), а по Парсевалю \|f - S_N\|^2 = \frac{T}{2}\sum_{n>N}(a_n^2+b_n^2).

Запись не периодична. Мы берём участок [t_0, t_0+T) и продолжаем его периодически искусственно. Если f(t_0) \ne f(t_0 + T - 0), у продолжения появляется разрыв на границе периода, и в этих точках возникает эффект Гиббса, которого в самом звуке нет. Если T содержит целое число периодов основного тона, скачок маленький.

Как считаются коэффициенты здесь. По M отсчётам периода через БПФ: c_n \approx \frac1M\sum_{j=0}^{M-1} f(t_j)e^{-2\pi i nj/M}, a_n = 2\operatorname{Re}c_n,\ b_n = -2\operatorname{Im}c_n (подробно на шаге 3). По M отсчётам различимы только гармоники n \le (M-1)/2, поэтому для коротких участков максимум N меньше 200.

Шаг 3. Откуда берётся коэффициент

Участок и сигнал те же, что на шаге 2.

Где здесь математика

Строго

1. Ортогональность. Для целых n, m \ge 0 по формулам произведения:

\cos n\omega t\cos m\omega t = \tfrac12[\cos(n-m)\omega t + \cos(n+m)\omega t],\quad \sin n\omega t\sin m\omega t = \tfrac12[\cos(n-m)\omega t - \cos(n+m)\omega t],
\sin n\omega t\cos m\omega t = \tfrac12[\sin(n+m)\omega t + \sin(n-m)\omega t].

Для целого k \ne 0: \int_0^T \cos k\omega t\,dt = \frac{\sin k\omega T}{k\omega} = \frac{\sin 2\pi k}{k\omega} = 0, \int_0^T \sin k\omega t\,dt = \frac{1 - \cos 2\pi k}{k\omega} = 0, а при k=0 \int_0^T 1\,dt = T. Отсюда

\int_0^T \cos n\omega t\cos m\omega t\,dt = \begin{cases}0,& n\ne m\\ T/2,& n=m\ne0\\ T,& n=m=0\end{cases},\quad \int_0^T \sin n\omega t\sin m\omega t\,dt = \begin{cases}0,& n\ne m\\ T/2,& n=m\ne0\end{cases},\quad \int_0^T \sin n\omega t\cos m\omega t\,dt = 0.

2. Вывод формул для коэффициентов. Пусть f(t) = \frac{a_0}{2} + \sum_{k\ge1}(a_k\cos k\omega t + b_k \sin k\omega t). Умножим на \cos n\omega t и проинтегрируем по периоду почленно. По п. 1 все слагаемые, кроме k = n, обнуляются:

\int_0^T f(t)\cos n\omega t\,dt = a_n\frac{T}{2}\ \Rightarrow\ a_n = \frac{2}{T}\int_0^T f(t)\cos n\omega t\,dt,\qquad b_n = \frac{2}{T}\int_0^T f(t)\sin n\omega t\,dt.

Для n=0: \int_0^T f\,dt = \frac{a_0}{2}T, поэтому формула для a_n верна и при n=0; ради этого свободный член записывают как a_0/2.

Когда почленное интегрирование законно. Достаточно равномерной сходимости ряда на [0, T]: тогда интеграл предела равен пределу интегралов, а умножение на ограниченную функцию \cos n\omega t равномерность сохраняет. Более общо достаточно сходимости в L^2: скалярное произведение \langle f, g\rangle = \int_0^T fg\,dt непрерывно по неравенству Коши — Буняковского. Если же мы просто определяем коэффициенты этими интегралами (так поступают для любой интегрируемой f), вопрос о законности отпадает, а сходимость ряда к f — отдельная теорема (шаг 2).

3. Комплексная форма. Из \cos u = \frac{e^{iu}+e^{-iu}}{2},\ \sin u = \frac{e^{iu}-e^{-iu}}{2i}:

f(t) \sim \sum_{n=-\infty}^{\infty} c_n e^{in\omega t},\quad c_n = \frac1T\int_0^T f(t)e^{-in\omega t}\,dt,\quad c_n = \frac{a_n - i b_n}{2},\ c_{-n} = \overline{c_n}\ (f\ \text{вещественна}),\quad a_n = 2\operatorname{Re}c_n,\ b_n = -2\operatorname{Im}c_n.

4. Численное интегрирование. На сетке t_j = jT/M: метод трапеций \int_0^T g\,dt \approx \frac{T}{M}\left(\frac{g_0}{2} + g_1 + \dots + g_{M-1} + \frac{g_M}{2}\right). Для периодической g (g_M = g_0) это совпадает с формулой прямоугольников \frac{T}{M}\sum_{j=0}^{M-1} g_j, а она для g = f e^{-in\omega t} и есть БПФ, делённое на M. Для записи f(t_0+T) \ne f(t_0), поэтому две оценки немного расходятся — это расхождение показано в числах.

Шаг 4. Спектр (ДПФ)

Клик по графику — послушать компоненту около этой частоты.
Изменений нет.

Где здесь математика

Строго

От коэффициентов ряда к ДПФ. Пусть вся запись длительности T = N\Delta t — один период. Заменим интеграл для c_k формулой прямоугольников на сетке t_n = n\Delta t:

c_k = \frac1T\int_0^T f(t)e^{-2\pi i k t/T}dt \approx \frac1{N\Delta t}\sum_{n=0}^{N-1} x[n] e^{-2\pi i k n/N}\Delta t = \frac{X[k]}{N},\qquad X[k] = \sum_{n=0}^{N-1}x[n]e^{-2\pi i kn/N}.

Гармоника k имеет частоту f_k = k/T = k f_s/N, шаг сетки частот \Delta f = f_s/N = 1/T: чем длиннее запись, тем мельче сетка.

Обратное ДПФ. Из дискретной ортогональности \sum_{n=0}^{N-1}e^{2\pi i (k-l) n/N} = N\delta_{kl}: x[n] = \frac1N\sum_{k=0}^{N-1}X[k]e^{2\pi i kn/N} — точно, без приближения.

Дискретное равенство Парсеваля. \sum_n |x[n]|^2 = \frac1N\sum_k |X[k]|^2.

Симметрия. Для вещественного x: X[N-k] = \overline{X[k]}, поэтому достаточно k = 0..N/2, а частоты выше f_s/2 — зеркальные копии. При удалении компоненты обнуляются сразу X[k] и X[N-k], и сигнал остаётся вещественным.

Алиасинг в ДПФ. Дискретные коэффициенты равны сумме непрерывных: X[k]/N = \sum_{m}c_{k+mN}. Если у сигнала есть гармоники выше f_s/2, они складываются с младшими.

Утечка спектра и окно. ДПФ неявно считает отрезок периодическим. Если в нём не целое число периодов синусоиды, на стыке скачок, и энергия «растекается» по соседним бинам. Окно Ханна w[n] = \frac12\left(1 - \cos\frac{2\pi n}{N}\right) плавно сводит края к нулю: боковые лепестки ниже (−31 дБ против −13 дБ у прямоугольного), но главный лепесток вдвое шире. Амплитуда синусоиды оценивается как A \approx 2|X[k]|/\sum_n w[n].

Сложность. Прямое вычисление — N сумм по N слагаемых, O(N^2). БПФ (Кули — Тьюки) делит сумму на чётные и нечётные n: X[k] = E[k] + e^{-2\pi i k/N}O[k], что даёт O(N\log N).

Фильтр обнулением бинов. Это «идеальный» фильтр с прямоугольной АЧХ. Его импульсная характеристика — sinc, поэтому у резких границ полосы возможен звон.

Шаг 5. Спектрограмма (STFT)

Клик по спектрограмме выбирает момент времени для среза.

Где здесь математика

Строго

STFT. Сигнал режут на кадры длины N с шагом H, каждый умножают на окно w и берут ДПФ:

X(m,k) = \sum_{n=0}^{N-1} x[n + mH]\,w[n]\,e^{-2\pi i k n/N},\qquad S(m,k) = |X(m,k)|^2.

В ТЗ та же формула записана с фазой от начала записи: \sum_n x[n]\,w[n-mH]\,e^{-2\pi i k n/N}. Замена n \to n + mH даёт множитель e^{-2\pi i k mH/N}, модуль которого равен 1, поэтому спектрограммы |X|^2 совпадают.

Децибелы. S_{\text{дБ}} = 10\log_{10}(S + \varepsilon): множитель 10, а не 20, потому что S — мощность (квадрат амплитуды). \varepsilon не даёт взять логарифм нуля в тишине. На графике показано S_{\text{дБ}} - \max S_{\text{дБ}}.

Сетка. Кадры идут через H/f_s секунд, частоты — через \Delta f = f_s/N. Длинное окно даёт мелкую сетку частот, но размазывает события во времени; короткое — наоборот. Перекрытие кадров делает картинку плавнее по времени, но не улучшает разрешение: оно задаётся длиной окна.

Принцип неопределённости Габора. Пусть \sigma_t^2 = \frac{\int (t-\bar t)^2|w(t)|^2dt}{\int|w|^2dt}, \sigma_f^2 = \frac{\int f^2|W(f)|^2df}{\int|W|^2df}. Тогда

\sigma_t\,\sigma_f \ge \frac{1}{4\pi},

и равенство достигается только на гауссовой функции e^{-t^2/(2\sigma^2)}. Доказательство — неравенство Коши — Буняковского для t\,w(t) и w'(t) вместе с равенством Парсеваля \int|w'|^2dt = 4\pi^2\int f^2|W|^2df и интегрированием по частям \int t\,(w^2)'\,dt = -\int w^2\,dt. Следствие: нельзя одновременно сделать окно сколь угодно коротким и сколь угодно узким по частоте.

У прямоугольного окна |W(f)|^2 \sim 1/f^2, и \int f^2|W|^2df расходится: в непрерывном случае \sigma_f = \infty. В дискретном случае частоты ограничены \pm f_s/2, поэтому число конечное, но большое и зависит от f_s.

Мел-шкала. m(f) = 2595\log_{10}(1 + f/700): почти линейна до ~700 Гц и логарифмична выше, как высота тона на слух; m(1000\ \text{Гц}) \approx 1000. Мел-банк — треугольные фильтры с центрами, равноотстоящими по m. Мел-спектрограмма — S_{\text{мел}}(m, j) = \sum_k H_j(k)\,S(m,k): в герцах полосы расширяются к высоким частотам.

Вход модели. AST получает лог-мел-спектрограмму: 16 кГц, окно 25 мс, шаг 10 мс, 128 полос, ровно 1024 кадра (короче — дополняется нулями), затем режет её на патчи 16×16 с шагом 10, то есть 12 \times 101 = 1212 патчей. В режиме «как на входе AST» здесь повторены эти параметры. Точный вход модели (с предыскажением 0,97, удалением постоянной составляющей и нормировкой из её препроцессора) будет показан на шаге 6.

Строго

Что показываем. Внутреннее устройство моделей здесь не разбирается. Факт один: на вход AST идёт лог-мел-спектрограмма из шага 5 (1024 кадра × 128 полос), нормированная как \hat S = (\ln S_{\text{мел}} - \mu)/(2\sigma) и разрезанная на патчи 16×16 с шагом 10. На выходе — числа z_i (логиты), по одному на класс.

AudioSet — многометочная задача. В одном клипе могут одновременно звучать речь, музыка и шум, поэтому AST обучена с независимой вероятностью на каждый класс:

p_i = \sigma(z_i) = \frac{1}{1 + e^{-z_i}},\qquad \sum_i p_i \ne 1\ \text{в общем случае}.

Softmax здесь был бы ошибкой: он заставил бы классы конкурировать, и уверенность «речь 0,9» отняла бы вероятность у «музыки». Поэтому в интерфейсе показана сигмоида — то, что модель реально выдаёт.

CLAP — выбор одной метки из списка. Звук и каждая текстовая метка переводятся в векторы единичной длины, логит — косинус между ними, умноженный на обученный масштаб e^{s}:

z_i = e^{s}\cos(\mathbf a, \mathbf t_i),\qquad p_i = \frac{\exp(z_i)}{\sum_j \exp(z_j)} = \frac{\exp(\cos_i/\tau)}{\sum_j\exp(\cos_j/\tau)},\quad \tau = e^{-s}.

Вероятности суммируются в 1 только по выбранным меткам: если подходящей метки нет, модель всё равно распределит 100% между имеющимися. Поэтому нужны метка «другое» и порог уверенности.

Энтропия. H(p) = -\sum_i p_i\ln p_i, 0 \le H \le \ln K. H = 0 — модель уверена в одной метке, H = \ln K — все метки равновероятны. Для независимых меток AST — бинарная энтропия каждой: -p\ln p - (1-p)\ln(1-p), максимум \ln 2 при p = 0{,}5.

Функция потерь. Для сигмоиды — бинарная кросс-энтропия L = -\sum_i [y_i\ln p_i + (1-y_i)\ln(1-p_i)], для softmax — кросс-энтропия L = -\ln p_{\text{верный}}. CLAP обучали контрастно: в батче из пар «звук — подпись» кросс-энтропия заставляет верную пару иметь наибольший косинус.

Обучение — градиентный спуск. Параметры \theta сдвигают против градиента: \theta \leftarrow \theta - \eta\,\nabla_\theta L, \eta — шаг обучения. Градиент считается по цепному правилу: \frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial z}\cdot\frac{\partial z}{\partial \theta}, и так слой за слоем (обратное распространение ошибки).

Для обеих пар «вероятность + потеря» производная по логиту получается одинаково простой:

\frac{\partial}{\partial z}\Big[-y\ln\sigma(z) - (1-y)\ln(1-\sigma(z))\Big] = \sigma(z) - y,\qquad \frac{\partial}{\partial z_i}\big[-\ln \operatorname{softmax}(z)_c\big] = p_i - [i = c].

Вывод для сигмоиды: \sigma'(z) = \sigma(z)(1-\sigma(z)), поэтому -\frac{y}{\sigma}\sigma(1-\sigma) + \frac{1-y}{1-\sigma}\sigma(1-\sigma) = \sigma - y. Оба равенства проверены в тестах конечными разностями.

Шум с заданным SNR. \text{SNR} = 10\log_{10}\frac{P_{\text{сигнала}}}{P_{\text{шума}}}, P = \frac1N\sum x[n]^2. Белый гауссов шум масштабируется так, чтобы SNR был ровно заданным.
