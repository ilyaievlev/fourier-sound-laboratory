## Правила качества

- Интерфейс и объяснения по-русски; формулы KaTeX с реальными числами записи.
- Математика отделена от Django в analyzer/services/, с аналитическими тестами.
  Не подгонять ответы, метрики и допуски; ошибку в ТЗ обозначать и исправлять явно.
- На каждом этапе проверять запуск и соответствующие тесты. Не выдавать
  validation, benchmark, синтетические или чужие метрики за собственный final test.
- Тестовые данные — только финальная оценка. Early stopping, пороги, выбор параметров
  и нормировки — по train/validation. Аномалии test насоса не участвуют в обучении.
- Каждый запуск: фиксированный seed, YAML, commit/status, снимок исходников,
  env.txt, data_manifest.json с SHA256, metrics.json, TensorBoard, safetensors.
- Перед запуском >30 минут — 50 шагов и показ конфига с пересчитанным временем.
- Фоновый running проверять по реальному процессу и heartbeat, а не одному PID.
  Checkpoint сохранять после эпохи; после остановки возобновлять подтверждённое
  состояние. Если оно отсутствует, новый запуск честно начинается с нуля.

## Зафиксированные факты и контракты моделей

- Исходная AST: MIT/ast-finetuned-audioset-10-10-0.4593,
  revision f826b80d28226b62986cc218e5cec390b1096902, BSD-3-Clause.
  AudioSet 527 классов — независимые sigmoid, не softmax.
- ASTFeatureExtractor той же revision: 16 кГц, 128 mel, 25 мс/10 мс,
  preemphasis 0.97, нормировка (x - (-4.2677393))/(2*4.5689974).
  При 1024 кадрах сетка 12×101; при 512 — 12×50, 602 токена со специальными.
- CLAP: laion/clap-htsat-unfused, revision
  8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a, Apache-2.0, 48 кГц,
  до 10 секунд, короткие repeatpad. Softmax по текстовым меткам, включая «другое».
- Кэш Hugging Face общий, исходные веса не перезаписывать и не скачивать повторно.
- B: artifacts/ast_project/ — from_pretrained safetensors, config, препроцессор,
  английские id2label/label2id, labels_ru.json, threshold.json по val,
  metrics/матрицы/манифест/LICENSE_NOTES.md/attributions.csv/model card.
- B использует общий training/common/project_audio.py: mono, ограничение входа
  48 кГц как в приложении, первые до 10 с, librosa soxr_hq → 16 кГц и zero-padding
  waveform до 160000 отсчётов, затем ASTFeatureExtractor. Не заменять это padding
  короткой спектрограммы. Контракт — audio_preprocessing.json; тест проверяет
  совпадение с ingest/float32-хранилищем приложения для 16/44,1/96 кГц.
- C: artifacts/anomaly_pump/ — модель ID в safetensors, model_config.json,
  feature_config.json, id_list.json, val-пороги, ROC/метрики/test_scores.csv.
- Обязателен artifacts/anomaly_pump/lof/: эмбеддинги train/val/test, соответствие
  строк файлам и ID, revision/настройки AST, обученные LOF для каждого ID (joblib),
  версии sklearn/joblib, пороги, ROC, метрики. Не пересчитывать в приложении.
- Для C общие признаки: 16 кГц, FFT/win 1024, hop 512, Hann, 128 mel,
  power=2, 10*log10(S+1e-10), единый training/common/features.py.
- ID classifier: train только норма, train/val 90/10 по ID; score — среднее
  -log p(истинный ID) по 64-кадровым вырезкам, порог — 90-й перцентиль normal val.
- LOF: исходная AST, mean last_hidden_state, 768 чисел; novelty=True,
  n_neighbors=20, отдельно на каждом ID. Fit только train, пороги только val.
  AUC и standardized pAUC (FPR≤0.1), ROC и confusion по каждому ID.
- Детектор учебный: применим к тому же типу машин; не выдавать его за диагностику
  произвольного микрофонного звука. В UI выбор ID и явное ограничение применимости.

## Известные особенности приложения

- N гармоник ограничен (M-1)/2 отсчётов; это показано пользователю.
- Без пауз физический SNR не измерим: в обратной связи использовать измеряемые
  признаки, «контраст кадров», клиппинг/тишину; не выдумывать SNR.
- Гиббс для пилы: 8.95% с поправкой порядка 1/(2N), тесты это учитывают.
- В STFT фаза от начала окна. Hann: sigma_t*sigma_f≈0.0817≥1/(4*pi).
- Исходные модели грузятся лениво, ресурсы vendor локальные; для офлайн
  использовать HF_HUB_OFFLINE=1. Не держать AST и CLAP вместе с тяжёлыми тестами.
- Галерея содержит 7 реальных примеров FSD50K/DCASE с источниками/атрибуциями
  и 7 помеченных синтетических примеров. Не называть их собственными записями.
